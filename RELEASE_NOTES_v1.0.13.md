IRICA v1.0.13 — Stop button + Close whole system

What's new
----------
- Stop button for the device-inquiry (استعلام دستگاه) card in the
  inquiries tab: kills the running inquiry process and resets the profile.
- "بستن سامانه" (Close whole system) button on BOTH panels (گمرک and
  استعلام): closes every running robot and shuts the panel down cleanly.
- Profile list visual refresh (cards, avatars, receipt/payment chips).

Upgrade
-------
Double-click IRICA-Setup-v1.0.13.exe. Your data in %LOCALAPPDATA%\irica
(profiles, settings, logs) is untouched. If the panel is running, the
installer closes it first.

SmartScreen note
----------------
The installer is not code-signed. If Windows SmartScreen appears:
click "More info" -> "Run anyway".
